<h1>Desafio II - Semana 08 - Programa de Bolsas React</h1>


<h2>Sobre o Projeto</h2>
Este projeto foi desenvolvido em grupo como parte do Programa de Bolsas React. O objetivo foi aplicar os conhecimentos adquiridos desde o início do programa para recriar uma ferramenta de produtividade, com base em um design específico. Utilizamos HTML, CSS, TypeScript, React e Tailwind CSS para construir e estilizar as páginas, incorporando funcionalidades de autenticação, navegação, banco de dados e design responsivo para desktop, tablet e mobile.

<h2>Estrutura do Projeto</h2>
<h3>Home</h3>
Botões para navegação entre as páginas de Login e Registro.
Validação de formulário e modal de confirmação de inscrição na Newsletter.
<br>
<h3>Login</h3>
Formulário de autenticação com validação de e-mail e senha.
Autenticação social via Facebook e Google configurada com Clerk.
<br>
<h3>Registrar</h3>
Formulário com validação completa dos dados do usuário.
Autenticação social e navegação com links.
<br>
<h3>Kanban</h3>
Interface arrastável com zoom e três colunas (To Do, In Progress, Done).
Colunas com rolagem vertical e indicador de tarefas.
Cards individuais com prioridade, título, progresso, participantes e contagem de comentários.
<br>
<h3>Configurações</h3>
Edição das informações básicas do usuário, incluindo upload de imagem e links para redes sociais.
Armazenamento das preferências do usuário e recarregamento da página com atualizações.
<br>
<h3>Perfil</h3>
Exibição de dados de contato, detalhes do usuário e relatório semanal com tarefas atribuídas.
<br>
<h3>404 - Página Não Encontrada</h3>
Tela de erro 404 com link de retorno para a Home.
<br>
<h3>403 - Página Bloqueada</h3>
Página de acesso restrito, que redireciona para o login caso o usuário não esteja autenticado.

<h2>Clonando o Projeto</h2>
Para clonar o projeto, siga as etapas abaixo:


<h4>1.Obtenha o link do repositório:</h4>

Acesse o repositório do projeto no GitHub.
Clique em <> Code e copie o link HTTPS ou SSH fornecido.

<h4>2.Abra o terminal:</h4>

Abra o terminal (ou Git Bash, no Windows).

<h4>3.Escolha a pasta de destino:</h4>

Navegue até a pasta onde deseja clonar o projeto.
Exemplo: cd /caminho/para/sua/pasta

<h4>4.Clone o repositório:</h4>

Execute o comando git clone <URL_DO_REPOSITORIO>, substituindo <URL_DO_REPOSITORIO> pelo link do repositório.

<h4>5.Acesse a pasta do projeto:</h4>

Após o clone, entre na pasta do projeto. Exemplo: cd nome-do-projeto

<h4>6.Instale as dependências:</h4>

Certifique-se de que o Node.js e o npm estão instalados.
Instale as dependências com: npm install

<h4>7.Inicie o servidor:</h4>

Para iniciar o servidor local e testar a aplicação, execute: npm run dev

<h4>8.Acesse a aplicação</h4>

Abra o navegador e acesse http://localhost:3000 (ou o endereço especificado no terminal).
